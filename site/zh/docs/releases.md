# 版本发布

产品页写 Vigilyx 做什么。跟 0.9.4 有关的行为放在这一页。

## 0.9.4 — 2026-11-13

- 默认融合策略是 `clustered_ds_v2`。历史名称 `ds_murphy`、`clustered_ds_v1`、`legacy_ds_murphy` 都会归一到它。Noisy-OR、Weighted Max 和 TBM 仍是显式可选项。
- `semantic_scan` 可以跑可选的 CPU ONNX 意图集成。未设置 `SEMANTIC_INTENT_SCORE_THRESHOLD` 时只做影子记录。计分命中向融合贡献复核级 Medium 分数 0.40。这个分数不是最终判定，也不单独决定处置。
- 托管邮箱平台下的租户标签是平台分配的标识，不是随机域名。已配置的平台包括 `wecom.work`、`onmicrosoft.com`、`onmschina.cn`、Outlook 防护主机，以及腾讯、网易、阿里的企业邮主机。
- 同一品牌的 `.com` 和 `.com.cn` 不算发件域嵌进了无关主机。`lenovo.com` 链到 `shop.lenovo.com.cn` 是中国站。品牌串出现在另一个注册域里，例如 `lenovo.com.attacker.example`，仍然算。
- 随机域名看注册域。6 个字母以内、仍带元音的标签，不会只因为辅音串被判成 DGA。没有元音、又不是拼音声母缩写的短标签，仍然算。
- 中国机构后缀上的公告页，以及留在发件机构自己站点上的下载，不算外部操作链接诱导。同一条链接如果在索要密码或账号，仍然算。
- 运行中的判定摘要按实际跑过的模块计数。杀毒和沙箱没启用时，分母常见是 25。编译期的流水线列表仍是 29 项，其中包括 `verdict` 和这些可选集成。
- MTA 默认：覆盖完整的安全判定会转发，低危也仅在覆盖完整时转发。中危及以上，以及覆盖不完整的安全或低危，进入隔离。严重以 `550 5.7.1` 拒收，不转发。只有转发会送到下游。`MTA_FAIL_OPEN` 默认为 false，Inline 判定不可用时返回 `451 4.7.1`。
- SMTP 外发数据安全审查和威胁判定分开。旁路只能审计可检查的邮件。MTA 可以对原本会转发的外发邮件执行 DLP。
- 这一版包含隐私模式、短时访问租约和独立审计账户。学习得到的 D-S 参数有单独的安装和回退。训练不会自动启用候选模型。
- 这一版的 Rust 工具链是 1.98.0。升级和回退步骤在 [更新与回退](/zh/docs/updating)。
